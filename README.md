**把钥匙和锁分开保管 —— 浏览器端、零服务器的文件加密工具**

> 只需一个 HTML 文件，即可在浏览器中完成 **AES-256-GCM** 加密。密钥与密文物理分离，适合存放个人隐私、财务记录或商业草稿。

---

## 🚀 30 秒快速上手

1. **打开页面**：克隆项目后，在浏览器中打开 `rlc-encryptor-v3.html`，或访问 [在线演示](https://lzyaa5a.github.io/rlc-encryptor)（如果你部署了 GitHub Pages）。
2. **拖入文件**：把你想加密的文件拖进窗口，或点击上传。
3. **一键加密**：点击"加密"，你会得到**两个文件**：
   - `你的文件.rlc` → 加密后的数据（可以上传到任何网盘或发给别人）
   - `你的文件.locker.txt` → **包含密钥的救命文件（请务必用 U 盘或密码管理器单独保存！）**
4. **解密**：需要时，用这个工具同时打开 `.rlc` 文件和对应的 `.locker.txt` 即可还原。

> ⚠️ **最重要的一条规则：** `.locker.txt` 文件就是你的全部密钥，**一旦丢失，数据永久作废，无法恢复。**

## 🧠 它到底怎么工作的？

<details>
<summary><b>🔐 点击展开：支持的算法体系与技术细节</b></summary>

### 1. 对称加密算法

| 算法 | 模式 | 密钥长度 | 用途 |
| :--- | :--- | :--- | :--- |
| **AES-256-GCM** | GCM | 256 位 | **数据加密**（文件分块 + 文本） |
| **AES-128-GCM** | GCM | 128 位 | **混淆区保护**（K1 分片嵌入噪声区） |

**AES-256-GCM 特性：**
- ✅ 认证加密 —— 同时提供机密性、完整性、真实性
- ✅ 内置 128 位认证标签，防篡改
- ✅ 每块数据使用独立 IV（12 字节随机值）

### 2. 密钥派生算法（KDF）

| 算法 | 用途 | 迭代次数 | 输出长度 |
| :--- | :--- | :--- | :--- |
| **PBKDF2-SHA256** | 从 K1 派生 AES-256 密钥 | **210,000** 次 | 256 位 |
| **PBKDF2-SHA256** | 从盐值增强密钥熵值 | 210,000 次 | 256 位 |

**PBKDF2 210K 迭代的作用：**
- 增加暴力破解成本（每次尝试需 0.5~1.2 秒）
- 抵抗 GPU 加速攻击
- 结合随机盐值，防御彩虹表攻击

### 3. 密钥生成（随机性）

| 密钥 | 格式 | 长度 | 熵值 | 生成方式 |
| :--- | :--- | :--- | :--- | :--- |
| **K1**（主密钥） | 大小写字母 + 数字 | 256 字符 | ~1,524 位 | `crypto.getRandomValues` |
| **K2**（混淆密钥） | 十六进制 | 32 字符 | 128 位 | `crypto.getRandomValues` |
| **盐值（Salt）** | 十六进制 | 64 字符 | 256 位 | `crypto.getRandomValues` |

**K1 字符集**：`ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789`（62 种字符 × 256 位 ≈ 2^1524 熵空间）

### 4. 混淆机制（混淆区保护）

| 组件 | 参数 | 说明 |
| :--- | :--- | :--- |
| **混淆区长度** | 4096 个十六进制字符 | 噪声填充区，用于隐藏 K1 分片 |
| **K1 分片数** | 32 片 | 每片 16 个十六进制字符（8 字节） |
| **分片偏移量** | 随机生成 | 每片在混淆区中的位置随机决定 |
| **混淆区加密** | AES-128-GCM | 用 K2 加密整个混淆区 |

**混淆流程**：
```
K1（256 字符）
  ↓ 转十六进制（512 字符）
  ↓ 拆为 32 片 × 16 字符
  ↓ 随机偏移嵌入 4096 字符噪声区
  ↓ AES-128-GCM 加密（用 K2）
  → 输出加密混淆区
```

### 5. 文件格式（RLC v3 容器）

```text
┌─────────────────────────────────────────────────────────┐
│  Header（对齐 1024 字节）                              │
│  ├── Magic: 0x52 0x4C 0x43 0x33 ('RLC3')             │
│  ├── Version: 0x03                                    │
│  ├── 原始文件大小（uint64）                           │
│  ├── 分块数量（uint32）                               │
│  ├── 每块大小（uint64）                               │
│  ├── 混淆区偏移（uint32）                             │
│  ├── 混淆区大小（uint32）                             │
│  └── 每块元数据（offset, originalSize, iv）           │
├─────────────────────────────────────────────────────────┤
│  Lead（2048 字节随机填充）                             │
├─────────────────────────────────────────────────────────┤
│  混淆区（AES-128-GCM 加密，含 IV）                    │
├─────────────────────────────────────────────────────────┤
│  Noise（256 字节随机填充）                             │
├─────────────────────────────────────────────────────────┤
│  加密数据块 1                                         │
│  加密数据块 2                                         │
│  ...                                                  │
│  加密数据块 N                                         │
└─────────────────────────────────────────────────────────┘
```

### 6. Locker 文件（密钥文件）

```text
========================================
  RLC v3 Locker - 加密密钥文件
========================================

[K1] 主密钥
[256 字符随机字母数字]

[K2] 混淆密钥
[32 字符十六进制]

[SALT] 盐值
[64 字符十六进制]

[OFFSETS] 混淆区 K1 片段偏移量
[32 个数字，逗号分隔]
```

> ⚠️ `.locker.txt` 是解密必需文件，丢失后无法恢复数据。

## 📊 文件处理能力速览

| 参数 | 值 |
| :--- | :--- |
| **分块大小** | 2 GB / 块 |
| **分块策略** | 超过 2GB 自动分块 |
| **并行处理** | Web Worker 并行加密（最多 2 并发） |
| **每块独立 IV** | 是，每块使用 12 字节随机 IV |
| **文本换行** | 加密前 `\n` → `\\n`，解密后还原 |
| **输出格式** | 文件：`.rlc` + `.locker.txt` / 文本：Base64 |
