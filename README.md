# RLC Encryptor v3 · 开源评估版

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES2020-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![Web Crypto](https://img.shields.io/badge/Web%20Crypto-API-brightgreen.svg)](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API)

**RLC Encryptor v3** 是一个基于 Web Crypto API 的浏览器端加密工具，采用 **AES-256-GCM + PBKDF2** 架构，支持文件与文本加密，核心设计理念为 **“密钥与密文物理分离”**。

---

## 🔐 支持的算法体系

### 1. 对称加密算法

| 算法 | 模式 | 密钥长度 | 用途 |
| :--- | :--- | :--- | :--- |
| **AES-256-GCM** | GCM（Galois/Counter Mode） | 256 位 | **数据加密**（文件分块 + 文本） |
| **AES-128-GCM** | GCM | 128 位 | **混淆区保护**（K1 分片嵌入噪声区） |

**AES-256-GCM 特性：**
- ✅ 认证加密（Authenticated Encryption）—— 同时提供机密性、完整性、真实性
- ✅ 内置 128 位认证标签（GCM Tag），防篡改
- ✅ 每块数据使用独立 IV（Initialization Vector），12 字节随机值

---

### 2. 密钥派生算法（KDF）

| 算法 | 用途 | 迭代次数 | 输出长度 |
| :--- | :--- | :--- | :--- |
| **PBKDF2-SHA256** | 从 K1（256 字符随机串）派生 AES-256 密钥 | **210,000** 次 | 256 位 |
| **PBKDF2-SHA256** | 从盐值（Salt）增强密钥熵值 | 210,000 次 | 256 位 |

**PBKDF2 210K 迭代的作用：**
- 增加暴力破解成本（每次尝试需 0.5~1.2 秒，取决于硬件）
- 抵抗 GPU 加速攻击（大规模并行尝试被严重拖慢）
- 结合随机盐值，有效防御彩虹表攻击

---

### 3. 密钥生成（随机性）

| 密钥 | 格式 | 长度 | 熵值 | 生成方式 |
| :--- | :--- | :--- | :--- | :--- |
| **K1**（主密钥） | 大小写字母 + 数字 | 256 字符 | ~1,524 位 | `crypto.getRandomValues` |
| **K2**（混淆密钥） | 十六进制 | 32 字符 | 128 位 | `crypto.getRandomValues` |
| **盐值（Salt）** | 十六进制 | 64 字符 | 256 位 | `crypto.getRandomValues` |

**K1 字符集**：
ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789

（62 种字符 × 256 位 ≈ 2^1524 熵空间）

---

### 4. 混淆机制（混淆区保护）

| 组件 | 参数 | 说明 |
| :--- | :--- | :--- |
| **混淆区长度** | 4096 个十六进制字符 | 噪声填充区，用于隐藏 K1 分片 |
| **K1 分片数** | 32 片 | 每片 16 个十六进制字符（8 字节） |
| **分片偏移量** | 随机生成 | 每片在混淆区中的位置随机决定 |
| **混淆区加密** | AES-128-GCM | 用 K2 加密整个混淆区 |

**混淆流程**：
K1（256 字符）
↓ 转十六进制（512 字符）
↓ 拆为 32 片 × 16 字符
↓ 随机偏移嵌入 4096 字符噪声区
↓ AES-128-GCM 加密（用 K2）
→ 输出加密混淆区

## 📦 文件处理能力

### 1. 分块加密

| 参数 | 值 |
| :--- | :--- |
| **分块大小** | 2 GB / 块 |
| **分块策略** | 超过 2GB 自动分块 |
| **并行处理** | Web Worker 并行加密（最多 2 并发） |
| **每块独立 IV** | 是，每块使用 12 字节随机 IV |

### 2. 文件格式（RLC v3 容器）

```text
┌─────────────────────────────────────────────────────────┐
│  Header（对齐 1024 字节）                              │
│  ├── Magic: 0x52 0x4C 0x43 0x33 ('RLC3')             │
│  ├── Version: 0x03                                    │
│  ├── 原始文件大小（uint64）                           │
│  ├── 分块数量（uint32）                               │
│  ├── 每块大小（uint64）                               │
│  ├── 混淆区偏移（uint32）                             │
│  ├── 混淆区大小（uint32）                             │
│  └── 每块元数据（offset, originalSize, iv）           │
├─────────────────────────────────────────────────────────┤
│  Lead（2048 字节随机填充）                             │
├─────────────────────────────────────────────────────────┤
│  混淆区（AES-128-GCM 加密，含 IV）                    │
├─────────────────────────────────────────────────────────┤
│  Noise（256 字节随机填充）                             │
├─────────────────────────────────────────────────────────┤
│  加密数据块 1                                         │
│  加密数据块 2                                         │
│  ...                                                  │
│  加密数据块 N                                         │
└─────────────────────────────────────────────────────────┘


### 3. Locker 文件（密钥文件）

========================================
  RLC v3 Locker - 加密密钥文件
========================================

[K1] 主密钥
[256 字符随机字母数字]

[K2] 混淆密钥
[32 字符十六进制]

[SALT] 盐值
[64 字符十六进制]

[OFFSETS] 混淆区 K1 片段偏移量
[32 个数字，逗号分隔]
⚠️ 重要：.locker.txt 是解密必需文件，丢失后无法恢复数据。
